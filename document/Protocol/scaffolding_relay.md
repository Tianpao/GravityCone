# Scaffolding Relay 版协议改动说明

本文档仅描述相对原协议**修改的部分**。原协议（房间码、联机网络、发现、信息获取等基础内容）见上游 [Scaffolding-MC 协议](https://github.com/Scaffolding-MC/Scaffolding-MC)。

改动目的：在 NAT 打洞失败时支持**中继联机**——房主选定中继节点并把节点 ID 编码进房间码，房客据此定向获取同一个中继节点。

## 1. 房间码内嵌中继节点 ID

### 格式

原房间码 `U/NNNN-NNNN-SSSS-SSSS` 的 16 个字符布局不变，其中两位被赋予新的语义：

| 位置 | 原语义 | Relay 版语义 |
|------|--------|--------------|
| N 部分最后一位（第 8 字符） | 网络名随机字符 | nodeID 低位字符 |
| S 部分最后一位（第 8 字符） | 密钥随机字符 | nodeID 高位字符 |

### 编码规则

按 34 字符集（`0-9, A-H, J-N, P-Z`，值 0~33）映射后，以小端序读出：

```
nodeID = v[网络名最后一位] + 34 × v[密钥最后一位]
```

- 值域：0 ~ 1155
- 网络名与密钥字符串本身**不变**（整段仍是 EasyTier 网络名/密钥），仅是部分字符不再是随机数

### 保留 ID

| 编码 | 值 | 含义 |
|------|-----|------|
| `00` | 0 | 房主使用**自用中继节点**（不追加公共中继；中继地址由房主通过其他通道提供） |
| `PP` | 805 | **不使用公共节点**（纯 P2P，不追加任何节点分发服务节点） |

正常 nodeID 范围 1~1155（排除 0 与 805；生成时若恰好编码出保留值需重试）。

### 校验规则变化

原校验（加权和 `sum(v_i × 6^(i%2)) % 7 == 0`）**保持不变**，但：

- 原实现用**位置 15**（密钥最后一位）微调满足校验——该位现被 nodeID 占用
- 校验微调位**移到位置 14**（密钥倒数第二位，权重 1）；对解析方透明，校验公式不变

### 兼容性

- 旧解析器解析 Relay 版房间码：格式、校验、网络名、密钥均可解析（nodeID 位只是"看似随机的字符"），可正常加入网络，只是没有定向中继能力
- 新解析器解析旧房间码：nodeID 读出随机值，需通过中继节点分发服务验证（见下），查无此节点则降级为列表节点

## 2. 中继节点分发

房主与房客通过**节点分发服务**获取公共节点（中继与 P2P 发现节点），客户端需内置该服务的访问凭据（API Key + 客户端标识）。

### 房主流程

1. 向节点分发服务请求节点列表（relay 中继 + p2p 发现节点）
2. 选定第一个 relay 节点，将其 **nodeID 编码进房间码**
3. EasyTier `-p` 参数使用：选定的 relay 节点 + p2p 发现节点 + 内置节点
4. 拉取失败或无 relay 节点 → 房间码编码 `PP`（不使用公共节点），仅用内置节点

### 房客流程

解析房间码 nodeID 后分支：

| nodeID | 行为 |
|--------|------|
| `PP`（805） | 纯 P2P：仅内置节点 |
| `00`（0） | 不追加公共中继，保留列表 p2p 发现节点 |
| 其他 | **按 ID 定向获取**：向节点分发服务指定该 nodeID，换取与房主相同的中继节点连接地址；同时追加列表 p2p 发现节点兜底 |
| 定向获取失败（旧房间码随机值/节点失效） | 降级：改用完整列表节点 |

nodeID 是节点分发服务中的**节点唯一标识**；房客必须解析出与房主相同的节点，双方才能汇聚到同一中继。定向获取的节点连接地址直接作为 EasyTier `-p` 参数。

## 3. 禁止 P2P（仅 GUI）

- 开关位于 App 设置页，状态持久化并同步至后端（CLI 无此入口，恒不生效）
- 开启后 EasyTier 以 `--disable-p2p true` 启动（P2P 直连被禁止，流量强制走中继）
- 关闭时 `--disable-p2p false`，P2P 优先、打洞失败自动走中继

## 4. EasyTier 启动参数变化

原私有模式参数 `--p2p-only`（禁止中继）**已移除**，替换为 `--disable-p2p true|false`。其余参数（`--private-mode`、加密 aes-gcm、压缩 zstd、端口白名单等）不变。网络从"纯 P2P 私有网络"变为"可中继"；流量内容仍为端到端加密。
